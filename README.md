## Tujuan Praktikum

Praktikum ini bertujuan untuk:
- Membuat tabel HTML untuk menyajikan data secara terstruktur.
- Membuat form dengan berbagai jenis input dan elemen pendukung.
- Menerapkan semantic HTML untuk membangun struktur halaman yang lebih bermakna.
- Menambahkan multimedia berupa audio dan video.
- Menerapkan validasi dasar pada form HTML.

## Langkah-Langkah Praktikum

1. Mempersiapkan text editor, yaitu Visual Studio Code, dan browser Google Chrome sebagai alat untuk membuat serta menguji halaman web.

2. Membuat folder proyek baru sebagai tempat menyimpan seluruh file praktikum.

3. Membuat file `index.html` sebagai file utama halaman web.

4. Membuat struktur dasar HTML pada file `index.html` sebagai fondasi halaman yang akan dikembangkan.

5. Membuat tabel HTML untuk menyajikan data secara terstruktur. Tabel terdiri atas tabel utama, baris, judul kolom, dan data yang ditampilkan pada setiap sel.

6. Menambahkan beberapa data ke dalam tabel dan mengatur struktur tabel agar informasi dapat ditampilkan dengan jelas.

7. Menggunakan atribut `colspan` untuk menggabungkan beberapa kolom menjadi satu sel. Selain itu, diperkenalkan atribut `rowspan` untuk menggabungkan beberapa baris dalam sebuah tabel.

8. Membuat form HTML untuk menerima data atau masukan dari pengguna. Form dilengkapi dengan label, input, dan tombol untuk menjalankan aksi pengiriman data.

9. Menambahkan berbagai jenis input sesuai dengan kebutuhan data, seperti teks, email, kata sandi, angka, tanggal, radio button, dan checkbox.

10. Menggunakan radio button untuk memberikan pilihan yang hanya dapat dipilih satu, sedangkan checkbox digunakan untuk memberikan pilihan yang dapat dipilih lebih dari satu.

11. Menambahkan elemen `textarea` dan elemen pendukung lainnya pada form untuk menerima masukan pengguna dengan kebutuhan data yang lebih panjang.

12. Menghubungkan label dengan input agar setiap kolom memiliki keterangan yang jelas dan lebih mudah digunakan oleh pengguna.

13. Menambahkan validasi dasar pada form menggunakan atribut HTML seperti `required`, `min`, `max`, `minlength`, dan `maxlength`. Validasi digunakan untuk membantu memeriksa data yang dimasukkan pengguna sebelum data diproses.

14. Menerapkan semantic HTML untuk membuat struktur halaman yang lebih bermakna. Elemen yang digunakan meliputi `header`, `nav`, `main`, `section`, `article`, `aside`, dan `footer`.

15. Mengatur struktur halaman menggunakan elemen semantic agar bagian kepala halaman, navigasi, konten utama, bagian konten, konten mandiri, konten samping, dan bagian kaki halaman dapat dibedakan dengan jelas.

16. Menambahkan multimedia ke dalam halaman web berupa audio dan video. Elemen audio digunakan untuk menampilkan media suara, sedangkan elemen video digunakan untuk menampilkan media video.

17. Menambahkan kontrol pemutaran pada media agar pengguna dapat menjalankan, menghentikan, dan mengatur media yang ditampilkan pada halaman.

18. Membuat satu halaman yang menggabungkan beberapa elemen HTML lanjutan, yaitu semantic HTML, tabel, form, dan multimedia dalam satu halaman web.

19. Membuka file `index.html` menggunakan browser untuk menguji hasil praktikum. Pengujian dilakukan dengan memastikan tabel dapat ditampilkan dengan baik, form dapat menerima input, struktur halaman tersusun dengan benar, serta media dapat diputar.

20. Memeriksa kembali validasi form dengan mencoba memasukkan data yang sesuai dan tidak sesuai dengan aturan yang telah ditentukan.

21. Memeriksa kembali path dan nama file media untuk memastikan audio dan video dapat ditampilkan dengan baik.

22. Merapikan struktur HTML, nesting, indentasi, serta penamaan file agar kode lebih mudah dibaca dan dikelola.

23. Memastikan setiap input pada form memiliki label yang jelas dan elemen HTML digunakan sesuai dengan fungsi serta tujuan kontennya.

## Hasil Praktikum

Hasil dari praktikum ini adalah sebuah halaman web yang menerapkan berbagai elemen HTML lanjutan. Halaman tersebut dapat menyajikan data dalam bentuk tabel, menerima masukan pengguna melalui form, memiliki struktur halaman menggunakan semantic HTML, serta menampilkan multimedia berupa audio dan video.

Selain itu, form telah dilengkapi dengan validasi dasar untuk membantu memeriksa data sebelum diproses. Penggunaan semantic HTML juga membuat struktur halaman menjadi lebih jelas dan bermakna.

Berdasarkan praktikum yang telah dilakukan, dapat dipahami bahwa HTML tidak hanya digunakan untuk menampilkan teks, tetapi juga dapat digunakan untuk menyajikan data secara terstruktur, menerima input pengguna, membangun struktur halaman yang bermakna, serta menambahkan multimedia. Penggunaan tabel, form, semantic HTML, audio, video, dan validasi dasar dapat membuat halaman web menjadi lebih lengkap dan interaktif.
